# LeadFlow AI Backend

LeadFlow AI is a client-intelligence platform designed to help digital marketers and agencies discover, qualify, organize, and manage potential business prospects.

## Core Features

- User registration and authentication
- Owner authorization
- Trial and usage management
- Prospect discovery API
- Prospect verification/source tracking
- Lead management and CRM
- AI-assisted outreach generation
- Premium subscription management
- ₹799 payment workflow
- Secure payment webhook processing
